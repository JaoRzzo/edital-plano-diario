# Contribuindo para Edital → Plano Diário

Obrigado por considerar contribuir para nosso projeto! 🎉

## Como Contribuir

### 1. Fork o Repositório
```bash
git clone https://github.com/SEU-USUARIO/edital-plano-diario.git
cd edital-plano-diario
```

### 2. Criar uma Branch
```bash
git checkout -b feature/minha-feature
# ou
git checkout -b fix/meu-bug
```

### 3. Fazer Commits
```bash
git add .
git commit -m "Descrição clara da mudança"
```

### 4. Push e Pull Request
```bash
git push origin feature/minha-feature
```
Depois abra um Pull Request no GitHub.

## Padrões de Código

### JavaScript
- Use `const` por padrão
- Nomes descritivos para variáveis
- Indentação de 2 espaços
- Adicione comentários para lógica complexa

### SQL
- Use UPPERCASE para comandos
- Adicione índices em colunas frequentemente consultadas
- Documente schemas complexos

## Processo de Review

1. Seu PR será revisado por um mantenedor
2. Podem ser solicitadas alterações
3. Após aprovação, será merged para `main`

## Reportar Bugs

Crie uma issue com:
- ✅ Título descritivo
- ✅ Descrição detalhada
- ✅ Passos para reproduzir
- ✅ Versão do Node.js e SO

## Sugerir Melhorias

Crie uma issue com:
- ✅ Título claro
- ✅ Descrição da melhoria
- ✅ Casos de uso
- ✅ Possível implementação

## Dúvidas?

Abra uma discussion ou issue com a tag `question`
